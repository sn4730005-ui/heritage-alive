# تراثنا الحي 🏛️

منصّة عربية (RTL) بتصميم عصري لتوثيق **أبرز الشخصيات المصرية** في عدة مجالات، و**أبرز أعمال الرئاسة**، و**تطوّر التعليم في مصر** — مع **مكتبة فيديو** يستطيع **مالك المنصة فقط** إضافة الفيديوهات فيها وتعديلها وحذفها.

---

## 1) تشغيل المنصة

```bash
cd heritage
node server.js
```

ثم افتح المتصفح على: `http://localhost:3000`

> لا يحتاج المشروع إلى أي تثبيت حزم (`npm install`) — يعمل على Node.js فقط (تم اختباره على Node 20).

يمكن تحديد المنفذ وكلمة المرور الأولى عبر متغيرات البيئة:

```bash
PORT=8080 ADMIN_PASSWORD="كلمة-مرور-قوية" node server.js
```

## 2) الدخول كمالك

- زر **«دخول المالك»** في أعلى الصفحة (أو رابط «تسجيل دخول المالك» في التذييل).
- كلمة المرور الافتراضية عند أول تشغيل: **`Heritage2026!`**
- بعد الدخول تُفتح **لوحة المالك** وفيها خمسة تبويبات:

| التبويب | ما يمكن للمالك فعله |
|---|---|
| **الفيديوهات** | إضافة فيديو (رابط يوتيوب/فيميو **أو** رفع ملف MP4/WebM حتى 80MB)، تعديل عنوانه ووصفه وتصنيفه، حذفه، وربطه بشخصية معيّنة، ورفع صورة مصغّرة |
| **الشخصيات** | تعديل النبذة وأبرز الأعمال والمقولة والكلمات المفتاحية والصورة، وإضافة شخصية جديدة أو حذف شخصية |
| **الرئاسة** | تعديل نبذة كل رئيس وأبرز أعماله وإنجازات التعليم في عهده |
| **التعليم** | إضافة/تعديل/حذف محطات الخط الزمني لتطوّر التعليم |
| **الإعدادات** | اسم المنصة والشعار النصي ونصوص الواجهة، وتغيير كلمة مرور المالك |

كل عمليات الكتابة محمية على مستوى الخادم: أي طلب بدون **جلسة مالك صالحة** يُرفض بـ `401` — لا تعتمد الحماية على الواجهة فقط.

## 3) بنية المشروع

```
heritage/
├── server.js              خادم Node (stdlib فقط) + واجهة API + حماية المالك
├── data/
│   ├── db.json            كل المحتوى: الإعدادات، الشخصيات، الرئاسة، التعليم، الفيديوهات
│   └── sessions.json      جلسات المالك (تُنشأ تلقائيًا)
└── public/
    ├── index.html         الواجهة (RTL)
    ├── styles.css         التصميم (خطوط Cairo + Amiri محليًا)
    ├── app.js             منطق الواجهة ولوحة المالك
    ├── fonts/             الخطوط العربية (بدون اعتماد على شبكة خارجية)
    ├── images/            صور الشخصيات + صورة الواجهة الرئيسية
    └── uploads/           الملفات التي يرفعها المالك (فيديو/صور)
```

## 4) واجهة الـ API

| الطريقة | المسار | الوصف | الحماية |
|---|---|---|---|
| GET | `/api/content` | كل المحتوى العام | عام |
| POST | `/api/admin/login` | تسجيل دخول المالك `{password}` | عام |
| GET | `/api/admin/session` | التحقق من الجلسة | عام |
| POST | `/api/admin/logout` | تسجيل الخروج | مالك |
| POST | `/api/admin/password` | تغيير كلمة المرور `{current,next}` | مالك |
| POST | `/api/upload` | رفع صورة/فيديو (base64) | مالك |
| POST / PUT / DELETE | `/api/videos[/:id]` | إضافة/تعديل/حذف فيديو | مالك |
| POST / PUT / DELETE | `/api/figures[/:id]` | إضافة/تعديل/حذف شخصية | مالك |
| PUT | `/api/presidents/:id` | تعديل بيانات رئيس | مالك |
| POST / PUT / DELETE | `/api/education[/:index]` | إدارة محطات التعليم | مالك |
| PUT | `/api/settings` | نصوص الواجهة | مالك |
| GET | `/api/export` | تنزيل نسخة احتياطية كاملة | مالك |
| POST | `/api/import` | استعادة نسخة احتياطية | مالك |
| GET | `/api/health` | فحص حالة الخدمة | عام |

الحماية: ترويسة `Authorization: Bearer <token>` — والجلسة صالحة 12 ساعة.

## 5) النشر على رابط دائم

دليل كامل بخطوات جاهزة (Render / Railway / VPS + دومين + SSL / Fly.io + Docker) في الملف:
**[DEPLOY.md](DEPLOY.md)**

- ملفات جاهزة: `package.json`, `Dockerfile`, `Procfile`, `render.yaml`, `railway.json`, `fly.toml`.

## 6) ملاحظات مهمة

- **رفع الفيديوهات الكبيرة:** الحد الأقصى 80 ميجابايت للطلب الواحد. للفيديوهات الطويلة استخدم رابط يوتيوب (أخف وأسرع).
- **المعاينة داخل التطبيق:** مشغّل يوتيوب يحتاج إنترنت، لذا قد لا يعمل الفيديو المضمّن داخل معاينة داخلية معزولة — لكنه يعمل طبيعيًا بعد فتح الموقع في المتصفح أو نشره. الفيديو التعريفي المرفوع محليًا يعمل في كل الحالات.
- **الصور:** مأخوذة من ويكيميديا كومنز لأغراض تعريفية/تعليمية، وحقوقها لأصحابها. المحتوى التاريخي مُجمَّع من مصادر منشورة (ويكيبيديا، الأهرام، ماسبيرو، اليوم السابع) وهو قابل للتعديل بالكامل من لوحة المالك.
- **النسخ الاحتياطي:** انسخ ملف `data/db.json` ومجلد `public/uploads/` للاحتفاظ بكل المحتوى والملفات.
- **النشر:** أي منصة تدعم Node.js تكفي (Render / Railway / VPS…). شغّل `node server.js` واجعل `PORT` متاحًا، وغيّر كلمة المرور الافتراضية فورًا.
